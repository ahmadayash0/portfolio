# Ahmad Ayash — Portfolio

All text, images and projects live in **content.json**. Don't edit the HTML to change content.

## Updating the site
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open this repository → **Portfolio**.
3. Edit anything (add a project, upload images, change text) and click **Save**.
4. The live site updates automatically about a minute later.

## Adding a project
Portfolio projects → **Add** → name, subtitle, tab, how it opens, then upload the images in order.
Page/post counts and the badge are added automatically.

## Visitor stats
See who visits the site: https://ahmadayash.goatcounter.com

- Visitors per day and week, countries, phone or computer, and where they came from (WhatsApp, LinkedIn, Google…).
- Clicks are listed too: **Project: …** (which projects were opened), **Download CV**, **Contact: …** (WhatsApp, email…), **Leave a review (button)** and **Review submitted**.
- To get your own login, ask Mona to add you: Settings → Users → Add user.

## Arabic version
Write each field in English **or** Arabic and leave the other one empty. About a minute after you save, the empty one is filled in automatically with Google Translate (you'll see it in the dashboard and can edit it).
Text you wrote yourself in both languages is never changed, and names are not translated.

## Client reviews
Clients can send a review from the **Leave a review** button. New reviews go to a Google Sheet; tick **Approved** in the sheet and the review appears on the site.

## Showing up on Google
The site is set up so Google can find it when people search for "Ahmad Ayash", "Ahmed Ayash" or "أحمد عياش".

- Google Search Console shows how many people found the site on Google and what they searched for: https://search.google.com/search-console
- New sites can take a few days to two weeks to appear in Google results.
- To get your own access, ask Mona to add you: Settings → Users and permissions → Add user.

## Link preview
When the site link is shared on WhatsApp, LinkedIn, Facebook or X, it shows a card with Ahmad's photo, name and title (the image is `og-image.jpg`).
If an old link shows no picture, send it as `https://ahmadayash0.github.io/portfolio/?v=2` (WhatsApp remembers old previews).
